# TamboPay customer web — Style 2

Next.js 14, TypeScript and Tailwind CSS. This is a **non-payment demo** matching the approved vibrant consumer-friendly design direction. No real transactions, customer accounts or provider fulfillment are enabled.

## Run locally

```bash
cd frontend
npm install
npm run typecheck
npm run build
npm run dev
```

Open http://localhost:3000. The existing root Vite app remains available separately at port 5173 during migration. The backend remains the existing Node prototype until FastAPI parity is implemented and verified.
